# RecRoomPSVR2
Adds certain PSVR2 features to Rec Room builds via PSVR2Toolkit.

Adds:
- Adaptive Triggers for weapons (All Paintball and Laser Tag weapons are done)
- Headset HMD Rumble when you get headshot

Want to do:
- Change trigger deadzone on weapons to make it so you can't just click small enough to not need to use the adaptive triggers

Currently only for EpicQuest's build, but will be also updated for Radium.
